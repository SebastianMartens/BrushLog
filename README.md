# BrushLog

A tiny single-page app for tracking how often (and when) your kid brushes their teeth.

- Start/stop timer for each brushing session
- Table of past sessions with date, start time, end time, and duration
- Deezer music player
- Today / total / streak counters
- All data stored in the browser's `localStorage` — full privacy, no backend, no build step
- No ads, no tracking, no accounts ;-)

## Usage

Just open `index.html` in a browser. That's it.

## Files

- `index.html` — page structure
- `style.css` — styling
- `app.js` — timer logic, stats, and localStorage persistence
